Chromecast ADB setup

Lets Claude install Jellytip builds straight onto the Chromecast with Google TV 4K. About five minutes with the remote.

1Unlock developer options

  1. Open Settings → System → About.
  2. Scroll to Android TV OS build and press OK on it 7 times, until it says you are a developer.
  3. Go back to Settings → System → Developer options.
  4. Turn on USB debugging. Despite the name, this also turns on network debugging.

2Put the Chromecast on Tailscale

The build server isn't on your home Wi-Fi, so it reaches the TV through Tailscale.

  1. On the Chromecast, open the Google Play Store, search Tailscale, install it.
  2. Open Tailscale and sign in with the same account as the server. It shows a code to approve on your phone.
  3. Leave Tailscale switched on. Note the TV's address, which starts with 100.

3Send Claude the address

Claude then runs the commands below from the server.

adb connect 100.x.y.z:5555
adb install -r Jellytip-debug.apk
  1. The first time, the TV shows Allow USB debugging?
  2. Tick Always allow from this computer and press OK.

OrInstall from your laptop instead

No Tailscale on the TV. The laptop must be on the same Wi-Fi as the Chromecast; use the Wi-Fi address from Settings → Network & Internet.

brew install android-platform-tools
adb connect <tv-wifi-ip>:5555
adb install -r Jellytip-debug.apk

?If it doesn't connect

  1. unauthorized: the TV prompt was missed. Run the connect again and accept it on the TV.
  2. connection refused: USB debugging turned itself off after a reboot. Switch it back on.
  3. Times out: check Tailscale is still connected on the TV.
